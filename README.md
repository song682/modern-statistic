Modern Statistic
<img align="right" alt="Logo" width="128" height="128" src="docs/ModernStatistics.svg">
====

Backport 1.21.9+ tabbed statistic screen + better statistic screen. Makes your statistics easy to track and navigate.

# Features

- 🗃️ Modern Tabbed layout interfaces 
- 🔍 Searching, filtering, sorting, and grouping statistics
- 📊 Item and mob statistics are shown in a nice and clean visual grid
- 🖥️ Mobs are visually rendered on the screen because it looks nicer und makes finding them faster
- 🖼️ Some of statistics can be tracked via right-clicking a entry and pin to hud. 
- 📂 Saving and loading statistics files, as well as a tabbed interface for viewing multiple files.、
- Mores to come ......
